# Founder photos

Drop real photos here to replace the gradient/monogram placeholders on
`/about`:

- `javiera.jpg` — Javiera
- `sebastian.jpg` — Sebastián

`components/founder-photo.tsx` tries to load these automatically; if a file
is missing, it falls back to the placeholder with no broken UI. No code
changes needed once the photos are in place.

Suggested spec: square or 4:3, at least 1200px on the long edge, JPG or WebP.
